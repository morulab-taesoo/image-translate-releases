# 화면 번역 (Image Translate)

캡처한 화면의 글을 이 PC 안에서 읽고 번역하는 Windows 앱의 설치 파일을 올리는 곳이에요.

- [Releases](https://github.com/morulab-taesoo/image-translate-releases/releases)에서 `ImageTranslate-Setup-<버전>.exe`를 받아 실행하고 **설치**를 누르면 돼요 (관리자 권한 필요 없음).
- 설치한 앱은 하루 한 번 여기서 새 버전을 확인해서 알려 주고, 트레이 메뉴나 설정 → 정보에서 바로 업데이트할 수 있어요.

## 모드 런처로 설치·업데이트

[모드 런처](https://github.com/morulab-taesoo/mod-launcher-releases)를 쓰면 로컬 검색·화면 번역 같은 morulab 프로그램을 한 창에서 설치하고 업데이트할 수 있어요. 새 버전이 나오면 런처에 **업데이트** 버튼이 떠요.
