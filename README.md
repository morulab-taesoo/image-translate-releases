# 화면 번역 (Image Translate)

화면을 캡처하고 **번역**을 누르면, 그림 속 글자를 읽어 번역문을 원래 글 자리에 덮어 보여 주는 Windows 앱이에요. 글자 읽기와 번역은 모두 이 PC 안에서 해서, 화면 내용이 인터넷으로 나가지 않아요.

- 캡처: 영역·요소·창·모니터(마우스가 있는 모니터)·전체 화면(모든 모니터)·페이지(스크롤하며 이어 찍기). 기본 단축키는 **Win + Shift + S**예요.
- 번역: 12개 언어 중에서 골라요. 원문 언어는 알아서 알아봐요. 번역하지 않을 단어(제품 이름·사람 이름)를 저장해 둘 수 있어요.
- 그리기: 펜·형광펜·도형·글자·지우개·자르기. **선택** 도구로 그린 도형·글자를 옮기고 크기를 바꾸거나 지워요. 결과는 복사·저장(PNG·JPG·GIF)하거나 캡처한 자리에 겹쳐 띄워요.
- 녹화: **Win + Shift + R**로 화면을 MP4로 녹화하고, 앞뒤·가운데를 잘라 내거나 GIF로 저장해요.
- Claude 도구: Claude Code·Claude Desktop에 연결하면 Claude가 화면 캡처·글자 읽기·번역을 이 앱에 맡겨요.

## 설치

1. [Releases](https://github.com/morulab-taesoo/image-translate-releases/releases/latest)에서 `ImageTranslate-Setup-<버전>.exe`를 받아 실행하고 **설치**를 눌러요. 관리자 권한은 필요 없어요.
   - 서명되지 않은 프로그램이라 Windows가 "PC 보호" 창을 띄울 수 있어요. **추가 정보 → 실행**을 누르세요.
2. 설치가 끝나면 앱이 열리고, 시작 메뉴에 **화면 번역**이 생겨요.
3. 처음 번역할 때 번역 모델(약 6GB)을 한 번 내려받아요.

[모드 런처](https://github.com/morulab-taesoo/mod-launcher-releases)를 쓰면 런처의 **설치** 버튼 하나로 설치할 수 있어요.

- 64비트 Windows에서 돌아요. 글자 읽기와 번역은 Intel GPU에서 가장 빠르고, GPU에 못 올리면 CPU로 넘어가서 느려져요. AMD·NVIDIA 그래픽 PC는 llama.cpp(Vulkan)로 그래픽에서 번역해요 (처음 한 번 약 37MB와 모델을 받아요).

## 쓰는 법

1. **＋ 새 캡처**(Ctrl+N)를 누르거나 어디서든 **Win + Shift + S**를 눌러 찍어요. 그림 열기(Ctrl+O), 끌어다 놓기, 붙여 넣기(Ctrl+V)도 돼요.
2. **번역**(Ctrl+T)을 누르면 문단마다 번역문이 그림에 채워져요. 화살표(⌄)에서 번역할 언어를 바꿔요.
3. 오른쪽 **문단 패널**(Ctrl+L)에서 문단마다 번역을 켜고 끄거나, 읽은 글을 고쳐 다시 번역해요.
4. **복사**(Ctrl+C)·**저장**(Ctrl+S)·**제자리에 띄우기**로 결과를 써요. `원문 | 번역`은 Space로 번갈아 봐요.

창을 닫아도 트레이에 남아서 단축키로 바로 캡처할 수 있어요. 설치할 때 'Windows를 켤 때 트레이에서 조용히 시작'을 켜 두면 켤 때마다 따로 열 필요가 없어요.

### Claude에서 쓰기

설정 → **Claude**에서 **Claude Code**·**Claude Desktop** 옆 **연결**을 눌러요. 그다음 Claude에게 "내 화면 좀 봐 줘", "뒤에 가려진 카카오톡 창 읽어 줘", "이 그림 번역해 줘"처럼 부탁하면 돼요.

- 연결한 뒤 Claude Desktop은 완전히 껐다 켜고, 열려 있는 Claude Code 세션에서는 `/mcp`로 다시 연결해요.
- Claude가 쓰는 도구: `capture_screen`, `list_windows`, `capture_scrolling`, `read_text`, `translate_image`, `keep_untranslated`, `list_untranslated_words`.

## 업데이트

- 앱이 하루 한 번 새 버전을 확인해서 트레이 알림으로 알려 줘요. **트레이 메뉴 → 업데이트 설치**나 **설정 → 정보 → 업데이트**를 누르면, 받은 뒤 앱이 잠깐 꺼졌다가 새 버전으로 다시 켜져요. 설정과 모델은 그대로예요.
- 자동 확인은 설정 → 정보 → **자동으로 확인**에서 꺼요.
- 모드 런처를 쓰면 새 버전이 나왔을 때 런처에 **업데이트** 버튼이 떠요.

## 지우기

Windows 설정 → 앱에서 **화면 번역**을 제거해요. 내려받은 모델과 설정(`%USERPROFILE%\.image-translate`)도 지울지 물어봐요. Claude 연결도 같이 끊어요.

## 알려진 한계

- 오른쪽에서 왼쪽으로 쓰는 글(아랍어 등)과 세로쓰기는 아직 제대로 그리지 못해요.
- 번역문은 원래 글자의 크기와 굵기(보통·굵게)만 따라요. 기울임과 글꼴 종류는 따르지 않아요.
- 페이지 캡처는 스크롤하면 새로 불러오는 페이지나 움직이는 광고가 있으면 이음매가 어긋날 수 있어요.
- 녹화할 때 화면 소리는 Windows 소리가 음소거면 녹음되지 않아요.
